# Legacy HTML v5

`BlockBlast_Simulator_v5.html` là bản mô phỏng thuần JavaScript của chiến thuật cũ. Nó **không đồng bộ thuật toán mới v6**, không nhận screenshot và không kiểm tra APK.

Để test v6 trực tiếp bằng chính bộ nhận diện/solver Android, mở `../screenshot-debug/start-dashboard.bat` hoặc `start-dashboard.sh` rồi tải ảnh PNG/JPG lên giao diện tại `http://127.0.0.1:8765`.
